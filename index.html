User Manual

Learn how to use the EventHub mobile application.

1. Register an Account

Open the application, select Register, enter your details, and create your account.

2. Login

Enter your email and password to access the application dashboard.

3. Browse Events

Search and filter events using categories, dates, and event titles.

4. Create Events

Promoters can create, edit, and manage events while uploading flyers and venue information.

5. Open Event Locations

Users can open event venues directly using Google Maps integration.

Developer Profile

Andre Cross

Andre Cross is the lead developer and designer behind EventHub. The application was developed using .NET MAUI, C#, XAML, SQLite, and Figma. The project demonstrates skills in mobile application development, UI/UX design, MVVM architecture, database integration, and native mobile functionality.
